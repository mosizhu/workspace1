# Prometheus-Alert-Handler 告警黑名单

## 规则说明
mop-prome-alert 每次处理告警时，需读取本记忆中的黑名单，若告警匹配则直接忽略。

## 黑名单字段
- **alertname**: 告警名称（必填，支持模糊匹配）
- **instance**: 实例地址（可选）
- **match_type**: 匹配类型
  - exact：完全匹配（默认）
  - contains：包含匹配（匹配告警内容）
  - regex：正则匹配
- **description**: 说明（可选，记录为什么加入黑名单）

## 黑名单规则
| alertname | instance | match_type | description |
|-----------|----------|------------|-------------|
| DMTablespaceUsageHigh | 172.20.23.54:5236 | exact | 该实例告警因缺少凭据且Agent选择错误被阻塞(blocked_no_credentials_wrong_agent)，加入黑名单 |

## 匹配逻辑
1. 收到告警后，读取本记忆中的黑名单
2. 逐条匹配：alertname + instance 同时命中则过滤
3. match_type 决定匹配方式
4. 匹配上 → 告警丢弃，不触发后续操作

## Skill 操作指引
- **添加黑名单**：用户告知"将告警 X 加入黑名单" → 更新此记忆，添加新规则
- **移除黑名单**：用户告知"将告警 X 从黑名单移除" → 更新此记忆，删除对应规则
- **查询黑名单**：用户要求查询黑名单 → 读取此记忆并输出列表

## 更新方式
通过记忆系统更新，或使用 Blacklist Manager Skill 进行维护。
