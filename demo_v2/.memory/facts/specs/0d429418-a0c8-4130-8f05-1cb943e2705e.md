Oracle 容量预测分析中，必须排除系统表空间（如 SYSTEM、SYSAUX、UNDOTBS 等）。只分析用户数据表空间（如 USERS、EXAMPLE、业务表空间）的增长趋势。

原因：系统表空间的使用模式是固定的，不会因业务增长而显著变化，纳入分析会干扰趋势预测的准确性。

排除规则：
- SYSTEM：排除
- SYSAUX：排除
- UNDOTBS*：排除
- TEMP：排除
- 其他以 SYSTEM/SYSAUX/UNDOTBS/TEMP 开头的表空间：排除
- 所有用户自定义表空间：纳入分析
